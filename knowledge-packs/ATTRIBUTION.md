# Datasets

This project includes third-party datasets:

## Exercises Dataset
- **Source**: https://github.com/hasaneyldrm/exercises-dataset
- **License**: CC0 1.0 Universal (Public Domain)
- **Contents**: 1,324 exercises with muscle group, equipment, and multilingual instructions
- **Processed**: `knowledge-packs/fitness-pack/exercises-full.json`

## Foods Dataset
- **Source**: https://github.com/suyogshejal2004/caltrack-data
- **License**: MIT (per the original repository)
- **Contents**: 1,015 food items with macronutrient data per 100g
- **Processed**: `knowledge-packs/fitness-pack/foods-full.json`
